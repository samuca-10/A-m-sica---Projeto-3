# Projeto de Autoria Web - 3º Bimestre: A Música e seu Encanto

## Tema 
O tema escolhido foi música


## Integrantes
- Amabili Thaine Bezerra da Silva 
- Isabela Vitória Cardoso de Araújo
- Samuel Nóbrega Rocha Medeiros
- Sofia Mayara Olívio Nóbrega

## Descrição
O site apresentará informações sobre gêneros populares, cantores e cantoras de destaque, suas trajetórias, principais obras e contribuições para a música, além de curiosidades e acontecimentos importantes que marcaram a história musical.

## Páginas
- index.html: apresentação geral do site e convite para a navegação das próximas páginas
- generos.html: apresentação dos gêneros, acompanhado de sua origem, história e curiosidades
- artistas.html: de acordo com os gêneros apresentados, artistas respectivos, junto com um resumo de sua tragetória musical
- curiosidades.html: curiosidades, e conclusão sobre o tema

## Uso de IA
O grupo utiizou IA para a melhor compressão das seguintes propriedades:

Transições e transformações
* transition: transform 0.4s ease
* transition: transform 0.3s ease
* transform: translateY(-5px)
* transform: translateY(-3px)

Listas
- list-style: none

Textos
* font-size: 1.4rem
* font-size: 1.2rem
* font-size: 1.1rem

A pesquisa relacionada ao conteúdo do site foi feita a partir de site informativos, como Wikipédia e ademais.
